# SIH26154 — 5 minute demo

1. Open the dashboard.
2. Explain the top pipeline: Source → Understand → Content DNA → Transform → Validate → Review → Audit.
3. Upload `storage/demo_incident_report.txt`.
4. Point out SHA-256, page count and security scan.
5. Click **Build Content DNA**. Explain that facts, entities, events and claims become a shared evidence representation.
6. Click **Generate Executive Brief**. Explain that the output is created from Content DNA, not an uncontrolled second reading.
7. Review the risk assessment and recommended actions.
8. Click **Approve after human review**. Explain that approval is a human decision.
9. Point to the audit trail and hash chain.
10. Explain that this is a free local prototype. An OpenAI provider can be enabled later, and the provider can be swapped in a production architecture.
