SIH26154 — START HERE

1. Open this folder in VS Code.
2. Open Terminal A and run:
   .\.venv\Scripts\Activate.ps1
   python -m pip install -r backend\requirements.txt
   python -m uvicorn backend.app:app --host 0.0.0.0 --port 8000

3. Open Terminal B and run:
   .\.venv\Scripts\Activate.ps1
   cd frontend
   npm run dev

4. Open:
   http://localhost:3000

5. Upload:
   Click "Choose a file" -> select PDF/DOCX/TXT.
   The upload is sent to the backend on port 8000.

6. Demo without a file:
   Click "Try the included demo document".

IMPORTANT:
- Do NOT recreate Python.
- Do NOT change Windows Python PATH again.
- The virtual environment is .venv.
- Backend = port 8000.
- Frontend = port 3000.
